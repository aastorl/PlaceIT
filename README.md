# 🗺️ PlaceIT

An iOS app built with SwiftUI and MapKit that allows users to save and view their favorite places on an interactive map. Ideal for marking personal landmarks like coffee shops, monuments, or any meaningful location.

## 🚀 Features

- 🗺️ Interactive map with annotations.
- ➕ Add custom places with name and favorite toggle.
- 📍 Save locations and display them as map annotations.
- 🧾 View saved places in a horizontal scrollable sheet.
- ❌ Delete saved places from the list.
- 🎨 Dynamic UI with **Light and Dark Mode** support.
- 📦 Clean **MVVM architecture** for scalability and maintainability.

## 🛠️ Built With

- **SwiftUI** for declarative and modern UI.
- **MapKit** for map rendering and interaction.
- **MVVM Architecture** for a clear separation of concerns.
- **Color Assets** with support for dark/light mode.
